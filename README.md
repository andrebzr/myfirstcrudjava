# 📦 CRUD de Produtos em Java

Meu primeiro projeto CRUD (Create, Read, Update, Delete) desenvolvido em Java, 
rodando via console. O sistema permite cadastrar, listar, atualizar, deletar 
e ordenar produtos, com validação de dados.

## 🚀 Funcionalidades

- ✅ Cadastrar produto (nome e preço)
- ✅ Listar todos os produtos cadastrados
- ✅ Atualizar dados de um produto pelo ID
- ✅ Deletar um produto pelo ID
- ✅ Ordenar produtos por preço (crescente/decrescente)
- ✅ Validação de entrada (nome vazio, preço negativo, entrada não numérica)

## 🛠️ Tecnologias

- Java 21
- Eclipse IDE

## ▶️ Como rodar

1. Clone o repositório: git clone https://github.com/andrebzr/myfirstcrudjava.git
2. Abra o projeto no Eclipse
3. Execute a classe `Main.java` (Run As → Java Application)
